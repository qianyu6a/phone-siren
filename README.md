# 手机警报器 · 网页版

把流行的「手机警报器」模拟器复刻成**单文件网页**：一个 `index.html`，零依赖、零构建，手机浏览器打开即用。

🔊 在线体验：**https://qianyu6a.github.io/phone-siren/**

## 这是什么

一个警灯 / 警笛模拟面板。点按按钮即可听到对应的警报音，顶部警灯条同步闪烁。所有音效都由 **Web Audio API 实时合成**（振荡器 + LFO 扫频），不含任何音频文件。

## 功能

| 模块 | 按钮 | 说明 |
|---|---|---|
| 号角与广播 | 气笛号角 | 按住发声的低音铜管号角 |
| | 车外广播 | 按住录音、松开回放（需麦克风权限 + https） |
| 战术警灯 | 自动联动 | 警灯随警笛节奏闪烁 |
| | 模式 1 / 2 / 3 | 示警 / 双爆 / 六循环 三种闪灯律动 |
| | 拦停检车 | 前射灯：白灯常亮 + 琥珀慢闪 |
| 手动电笛 | 高音电笛 | 长按音调爬升，松开滑落 |
| | 低音电笛 | 长按爬升，松开带"飞轮拖尾"惯性衰减 |
| 巡航警报 | 巡航 / 慢速 / 快速 Wail | 经典巡逻警笛，三档速度 |
| 急促警报 | 急促 Yelp | 快速扫频 |
| | 逐击变调 | 逐级跳变的变调警笛 |
| | 极速穿透 | 极高频快速扫频，穿透力强 |
| 特种与轮换 | 战术颤音 | 高频颤音 |
| | 救护 Hi-Lo | 高低双音交替（救护车） |
| | 自动 | 每 5 秒随机轮换一种警笛 |
| 双音并发 | 并发 A / B | 两种警笛同时发声 |
| 系统控制 | 重低音脉冲 | 低频脉冲叠加 |
| | 系统设置 | 调音设置：主音量 / 音调 |
| | 低功率 | 音量 -12dB |
| | 静音 | 一键全停 |

## 使用

直接打开网页 → 点「同意并进入」→ 点按钮。首次点按后浏览器才允许出声（自动播放策略）。

## 本地运行

下载 `index.html`，双击即可。如需"车外广播"（麦克风），请用 `https://` 或 `localhost` 打开，浏览器才允许访问麦克风。

## 提醒

本页面为**娱乐模拟**，仅供技术学习。请勿在道路、商场、公园、居民区等公共场所播放，严禁用于冒充特种车辆等违法行为。

## 技术

纯原生 HTML / CSS / JavaScript + Web Audio API，无框架、无依赖、无构建步骤。
